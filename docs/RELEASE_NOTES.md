## New in 1.0.23

- **The icon is the DRAUPNE mark without its corner brackets, bigger:** the window, the taskbar, the installer and the phone app's launcher. The boot animation keeps the brackets.
- **No flash of the UI before the boot animation:** the window opens black.
- Phone app pc.17 (bundled): the launcher icon; otherwise as pc.16.

The phone app in this release is DRAUPNE Flight 2.3.0-pc.17 (SETUP > Phone setup hands it over by QR code). It only changes the icon; pc.16 works the same.

## Files

- **`DRAUPNE-Link-Setup-*.exe`**: the installer. Run it, approve the Windows prompt once; the setup wizard opens on the first start. Windows may say *"Windows protected your PC"* because it isn't code-signed: **More info → Run anyway**.
- **`DRAUPNE-Link-*-windows.zip`**: the portable version. Unzip and run `DRAUPNE Link.exe`.
- **`DRAUPNE-Flight-*.apk`**: the phone app this version installs. The setup wizard hands it to the phone by QR code.
