## New in 1.0.55

With **DRAUPNE Flight 2.3.0-pc.43**. Update the PC app, then the phone (UPDATE PHONE APP, drone disarmed).

Not yet tried on a drone or real phone: bench-test with props off first.

### Fixed
- **Motion detection on real phones:** many phones gave it no picture for 16:9 video, so it never found anything. The PC now says so if a camera still gives none.
- **Tour:** the Overwatch demo asks to close an open virtual fleet instead of showing an empty map. The BTR now runs every time.

### New
- **Picture turned once, turned everywhere:** a phone's upside-down setting also turns its observation tile, overwatch card, clips and previous flights.
- **OSD on each observation tile.**
- **Tour:** the box and the map window can be moved and resized. The pins sheet closes after its step.

All details: [CHANGELOG](https://github.com/MelonNO/draupne-link/blob/main/docs/CHANGELOG.md).
